## 1. 开篇三章

读者在前三章决定是否追读。目标：快速建立“谁、处境多糟、凭什么能翻身、接下来有什么好看”。

- 第一章第一段就要有人在做事、有麻烦。不要从世界观、天气、梦境、长篇回忆开始。
- 主角的困境要具体：被退婚、欠债、被逐出宗门、明天要被献祭。
- 金手指或核心卖点在前三章出现，至少露出端倪。
- 第一个小爽点或小悬念在第一章结尾前兑现或抛出。
- 世界观只给能看懂当前冲突的最少量。
- 出场人物控制在 3–5 个有名角色，每个都要一出场就有辨识度。

## 2. 单章结构

一个够用的模板（不必拘泥）：

1. 承接（10%）：接上章钩子，最快速度回到冲突里。不要复述上章。
2. 推进（40%）：主角为目标采取行动，遭遇阻力，局面变化。
3. 升级（30%）：冲突加剧或发生意外，主角做出选择。
4. 兑现/转折（15%）：本章的爽点或信息揭示。
5. 钩子（5%）：新问题。

## 3. 章末钩子

钩子类型，轮换使用，不要连续几章都是同一种：

| 类型 | 做法 |
|---|---|
| 危机降临 | 新的威胁出现在门口 |
| 身份揭示 | 某人的真实身份露出一角 |
| 意外反转 | 以为赢了，其实中计了 |
| 选择悬置 | 主角必须在两个坏选项中选一个，章末还没选 |
| 信息炸弹 | 一句话改变读者对前文的理解 |
| 期待兑现前 | 爽点就要来了，下一章才打脸 |
| 异常细节 | 一个不对劲的小东西，不解释 |
| 情感悬置 | 一句话没说完，一个人转身走了 |

钩子要真实兑现。连续“钓鱼”不兑现，读者会觉得被耍。

## 4. 爽点：铺垫与兑现

公式：**压（让读者憋气）→ 蓄（主角准备，读者知道他有底牌）→ 放（反转）→ 收（反馈）**。

- 压的强度要和放的力度匹配。轻视、羞辱、不公要具体，让读者真的生气。
- 蓄的阶段让读者比反派知道得多，这是“期待感”的来源。
- 放要干脆，一两句话完成反转，不要拖泥带水。
- 收是最容易被忽略、也最出效果的一步，见第 7 节。
- 爽点类型：打脸、扮猪吃虎、越级战胜、获得机缘、身份曝光、复仇、被认可、智商碾压。同一卷内轮换。

## 5. 战斗

- 写战斗是在写人物：怎么打取决于他是谁、想要什么、怕什么。
- 交代清楚：谁在哪、手里有什么、优劣势在哪。读者看不懂局面就不会紧张。
- 战斗要有转折：一方占优 → 意外 → 局势翻转。一路平推的战斗一句话写完。
- 动作描写挑关键几下写细，其余概括。不要逐招报菜名。
- 代价：受伤、法宝损坏、消耗底牌、暴露秘密。战后状态要同步到 memory/state.md。
- 节奏：越激烈句子越短。

## 6. 升级、突破与获得宝物

- 突破要有代价和契机，不要“水到渠成”地自然突破。最好的突破发生在危机里。
- 升级后要马上找到地方用：读者需要看到“变强了”的具体效果。
- 境界名、能力上限必须符合 lore/world/ 的力量体系。新能力登记到角色文件。
- 获得宝物：写清来路、限制和代价。没有限制的宝物会让后面所有冲突失去张力。

## 7. 围观与反馈

爽点的“收”靠反馈，反馈要分层且有差异：

1. 对手：从嚣张到不敢相信，再到具体的后果（丢了什么、要付出什么）。
2. 关键人物：师父、心上人、仇人，他们的反应决定情绪落点。
3. 围观群众：给一两个具体的人具体的反应，不写“众人倒吸一口凉气”。

> 例：输了赌注的胖修士把押注的玉牌攥在手里，半天没松开。旁边的小师妹拿胳膊肘捅他：“师兄，你押了多少？”
> “……别问。”

## 8. 日常与过渡章

- 过渡章也要有一件小事和一个小起伏。纯赶路、纯修炼不成章。
- 适合做的事：人物关系的推进、伏笔的埋设、世界观的自然展示、喘气的笑点。
- 篇幅尽量压缩，能合并就合并。

## 9. 悬念与伏笔

- 每条伏笔登记在 memory/threads.md，写清真相和回收计划，不然写着写着自己都忘了。
- 埋设要自然：藏在一个当时看起来有别的用途的细节里。
- 公平：回收时读者回头看，能找到当初的线索。
- 信息差：清楚地设计“读者知道什么、主角知道什么、反派知道什么”，这决定了每一场戏的张力。
- 不要在埋设的同一章或下一章就回收，除非是很小的悬念。
- 暗线：长期不揭示的设定，正文中只能出现符合 threads.md“不可违反”约束的痕迹。

## 10. 感情线

- 关系变化要有具体事件推动：一次救命、一次误会、一次共同的秘密。
- 心动写在细节里：注意到对方不为人知的习惯，记住对方随口说的话。
- 推拉节奏：近一步、退半步。一直甜和一直虐都会让读者疲劳。
- 双方都有自己的主线和目标，不要让一方变成另一方的附属。

## 11. 注水识别

以下情况说明在凑字数，应删减：

- 复述上章或前几章已经写过的事。
- 同一个信息通过不同角色说了两遍。
- 大段与本章冲突无关的风景、衣着、设定说明。
- 角色在想“接下来该怎么办”，想了几百字最后什么也没决定。
- 战斗中逐招描写，但局势没有变化。

字数不够时，加一个场景、一次冲突或一层反转，而不是把现有段落写长。
