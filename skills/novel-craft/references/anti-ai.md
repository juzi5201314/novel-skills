## 1. 判断标准

一句话有 AI 味，通常是因为它**换到任何一本书、任何一个角色身上都成立**。“他深吸一口气，眼中闪过一丝坚定”可以放进一万本书里，所以读者一眼就跳过去了。

改写时问自己：这句话能不能只属于这个人物、这个场景、这本书？不能，就换成能的。

单个“缓缓”“仿佛”不是问题，人类作者也用。问题是密度和替代关系：当这些词代替了具体的观察，文字就空了。

## 2. 词句层：高频套话

| 类型 | 典型写法 | 往哪改 |
|---|---|---|
| 眼神戏 | 眼中闪过一丝精光/寒芒/复杂；眸光微动；眸子深邃 | 删掉，或换成一个可以被别人看见的动作 |
| 嘴角戏 | 嘴角勾起一抹弧度/冷笑；唇角微扬 | 让他说一句话，或者干脆不写表情 |
| 呼吸戏 | 深吸一口气；倒吸一口凉气；呼吸一滞 | 只在真有生理原因时写（跑累了、被掐住了） |
| 心理拟声 | 心中一凛/一紧/一动/一沉；心头一暖 | 写他接下来做了什么不同的事 |
| 万能修饰 | 缓缓、微微、淡淡、轻轻、一丝、一抹、一缕、些许、几分 | 大部分直接删，句子更有力 |
| 比喻连接 | 仿佛、宛如、犹如、恍若……一般 | 删比喻；保留的比喻要具体、新鲜、贴人物 |
| 安静套话 | 空气仿佛凝固了；落针可闻；鸦雀无声；时间仿佛静止 | 写一个具体的声音反衬：谁的椅子吱了一下 |
| 不可言说 | 难以言喻、无法形容、说不清道不明、前所未有 | 作者的工作就是形容出来 |
| 情绪打包 | 五味杂陈、百感交集、涌上心头、心中一暖 | 拆成一个具体的念头 |
| 身体套话 | 指节泛白、喉结滚动、瞳孔骤缩、身躯一震 | 一章最多一次；换成这个角色特有的反应 |
| 书面腔 | 弥漫着……的气息；交织；涟漪；璀璨；深邃；低语；某种 | 换成口语或具体名词 |
| 宿命收尾 | 命运的齿轮开始转动；一切才刚刚开始；他不知道的是…… | 删。让钩子由事件本身提供 |
| 对白标签 | 冷冷地说道、沉声道、淡淡道、轻声道轮流用 | 用“说”/“道”或动作代替 |

## 3. 句式层

- **“不是A，而是B”**：AI 最爱的转折，自带说教感。直接说B。
- **“不仅……更是……”**：同上。
- **排比三连**：“他的剑很快，很稳，很准。”三连一章用一次就够了，用多了像在念稿。
- **“他知道，……”“这一刻，……”**：叙述者在替读者划重点。删掉引导词，句子照样成立。
- **结构复制**：连续几句都是“主语+动作+修饰”，或连续几段都以“他”开头。打散：倒装一句，省略一次主语，插一句对白。
- **长度均匀**：每句都在 15–25 字之间，每段都三四行。人写东西会忽长忽短。一个字的句子也是句子。
- **形容词叠罗汉**：“冰冷、刺骨、带着死亡气息的寒风”。挑一个最准的。
- **翻译腔**：“他的脸上露出了一个笑容”“一个巨大的问题摆在了他的面前”。中文少用量词“一个”，少用“的”串长定语。

## 4. 结构层

- **每段一个总结句**：段末“这让他意识到……”“这就是……的代价”。删掉，相信读者。
- **场景都从环境开头**：“夜色如墨，月光洒落……”换成从人物正在做的事切入。
- **冲突当场化解**：AI 倾向于让矛盾马上被理性沟通解决。让冲突留下余波：有人记仇，有人吃亏，有事没说清。
- **梗概代替场景**：“经过一番激战，他终于胜出。”这是大纲，不是正文。要么完整写，要么一句带过且不加“终于”。
- **对称过度**：每个角色都说一句、每个场景都等长、正反两面都照顾到。好的故事是偏心的。
- **说明书段落**：连续一段在介绍设定或背景。拆开，塞进对白、冲突或人物的吐槽里。
- **章末上价值**：最后一段抒情、总结、展望。停在一个动作、一句台词、一个异常上。

## 5. 人物与情绪层

- **情绪直述**：“他很愤怒”“她感到委屈”。读者被告知了，就不会感受到。写行为，让读者自己得出结论。
- **情绪过于稳定**：所有人都冷静、得体、讲道理。人会迁怒、会嘴硬、会在不该笑的时候笑出来。
- **反应过于标准**：震惊就倒吸凉气，害怕就颤抖，感动就眼眶发红。每个人表达同一种情绪的方式应该不一样，这正是人设起作用的地方。
- **人人都是聪明人**：每个角色都在最优决策。让人物犯符合他性格的错误。
- **群众同质化**：围观者异口同声地惊叹。给一两个围观者具体的身份和私心：输了赌注的、暗暗记下这一招的、想着回去报信的。

## 6. 人味从哪来

- **带偏见的叙述声音**：叙述跟着视角人物的价值观和情绪走。穷小子看到法宝先想“能换几块灵石”，大小姐看到同一件东西先嫌它土。
- **可核对的细节**：数字、名字、牌子、价格、方位、伤口在哪边。“三块下品灵石”比“一些灵石”可信。
- **不完美的反应**：走神、记错、说错话、怕疼、饿、困、想上厕所。紧张关头想到无关的小事，是很真实的写法。
- **潜台词**：人物说的和想的不一样。读者看懂了而角色没说破，这是阅读快感。
- **从人物里长出来的幽默**：嘴贫的人吐槽、老实人说真话造成的尴尬、计划和现实的落差。不是叙述者抖机灵。
- **留白**：关键情绪处少写一句。哭不如强忍，解释不如沉默。
- **生活质感**：钱、吃饭、住哪、谁欠谁人情、身上的旧伤。修仙的人也要算账。
- **口语节奏**：语气词、省略、半截话、重复。“行，行，你说得对。”

## 7. 改写示例

**例一：情绪直述 + 套话**

> 改前：他深吸一口气，眼中闪过一丝坚定。他知道，这一次他绝不能退缩，因为这不仅仅是为了自己，更是为了家族的荣耀。
>
> 改后：他把退婚书折了两折，塞进袖子，冲堂上的人拱了拱手。“三年后，我上门来取回今日这句话。”

改了什么：删掉“深吸一口气”“眼中闪过”“他知道”“不仅……更是”；决心用动作和一句具体的承诺表现。

**例二：万能氛围**

> 改前：夜色如墨，冷风呼啸。整个小镇仿佛陷入了沉睡，空气中弥漫着一股不安的气息。
>
> 改后：镇上只剩酒馆还亮着灯。窗外有人敲了三下更，可打更的老周前天就下葬了。

改了什么：用一个具体的异常代替抽象的“不安”，悬念自己出现。

**例三：说明式对白**

> 改前：“师弟，你应该知道，我们青云宗是东域三大宗门之一，宗主是元婴后期的强者，门下弟子三千……”
>
> 改后：“青云宗？”摊主把找的钱又收了回去，“那你们宗门不缺这三文钱，这碗面算你二十。”

改了什么：宗门的地位从别人的反应里带出来，顺手给了一个笑点。

**例四：情绪命名**

> 改前：听到这个消息，她感到非常委屈和愤怒，眼眶微微泛红。
>
> 改后：她“啪”地把筷子拍在桌上，又自己捡起来，低头扒饭，一筷子菜也没夹。

**例五：排比 + 比喻堆叠**

> 改前：他的剑快如闪电，稳如泰山，准如神射，宛如一道银色的流星划破夜空。
>
> 改后：对面那人刚抬起手，喉咙上就多了一道红线。他自己大概都没看清。

**例六：总结式章末**

> 改前：他望着远方的群山，心中百感交集。他知道，属于他的传奇，才刚刚开始。
>
> 改后：他推开客栈的门，掌柜的抬头看了一眼，手里的算盘停了。“客官……您昨天不是已经退房了吗？”

**例七：梗概式战斗**

> 改前：两人激战了三百回合，最终他凭借着顽强的意志取得了胜利。
>
> 改后（要写就写细，不写就一句带过）：打到后来，他左手已经抬不起来了，全凭一口气撑着。对方先跪下去的时候，他差点跟着一起倒。

## 8. 读 lint 结果

`novel.py lint` 的“AI 味”一栏按命中次数排序列出所有套话。处理方法：

- 看总密度。经验上低于 2 处/千字比较干净，超过 5 处/千字读者能明显感觉到。这只是参考线，不要为了压数字把正常的“说道”全换成生僻词。
- 同一个词命中 3 次以上，优先处理，重复比单次使用更扎眼。
- 逐处看语境：这里是不是最好的写法？能删就删，删不掉就换成具体描写。
- “叙述段长度变异系数”低于 0.4，说明段落长短太整齐，挑几段拆短或合并。
- lint 抓不到结构层和人物层的问题（总结句、情绪直述、梗概化），这些要人工通读，对照第 4、5 节。
