# 网文正文写作

动笔前先读 `AGENTS.md` 里本书的文风预设、正文格式和硬规则；预设的具体写法见 `references/styles.md`，反 AI 味细则与改写范例见 `references/anti-ai.md`，高频场景技巧见 `references/techniques.md`。本文件是所有文风通用的铁律。

## 一、核心铁律：写“正在发生的戏”，不写“旁白解说词”

大模型写小说最致命的毛病，是站在镜头外当“解说员”——用十几个短句概括过去几天发生了什么、解释双方为什么结仇、替角色总结局势，最后甩一句看似深沉的“金句”收尾。这叫**剧情梗概/纪录片解说词**，不叫小说正文。

1. **活在当下这一秒**：正文只写此时此地正在发生的动作、亲眼看见的细节、当场说出口的话。
2. **禁止插播回忆杀与背景总结**：不要在场景推进中突然切出三五段“这事本是为……那日……后来……那时他只想着……”来补背景。前因后果必须碾碎在当下的物件、伤势和对话交锋里带出来。
3. **禁止排排坐点名**：写多人场景时，严禁“A 做一个动作 → B 做一个动作 → C 做一个动作”或“A 喊一句口号 → B 骂一句 → C 冷笑一句”的签到式写法。用连贯的动作链和互动把人串起来（A 的动作引出 B 的反应，C 打断他们）。
4. **把架子放下来，严禁“端着写”**：不要把每句话都当成电影预告片字幕来写。删掉所有故作深沉的判词、格言、对偶金句，老老实实写人怎么做事、怎么说话。

## 二、段落与排版规范（拒绝“一句一行”与“密排文字墙”）

排版直接决定阅读体验。当前模型最容易犯两个极端：**要么每写一个句号就换行（一句一行的散文诗/电报体），要么既不缩进也不空行堆成密排黑块**。必须严格遵守以下排版标准：

### 1. 硬格式底线
- **默认标准格式**：**段首两个全角空格（`　　`）+ 段间空一行**（即段落之间必须有一个空行 `\n\n`）。
- 若 `AGENTS.md` 明确指定了其他格式（如“不缩进+段间空行”或“段首缩进+不空行”），按 `AGENTS.md` 执行；但**绝不允许出现“既无段首全角缩进、又无段间空行”的裸文本密排**。
- 全角中文标点，引号用 `“”` / `‘’`，省略号 `……`，破折号 `——`；严禁任何 Markdown 标记。

### 2. 段落是“镜头与呼吸单位”，不是“句号单位”
- **严禁“一句一行”碎段癌**：绝不能每写完一个句号就按回车！连续 3 个以上只有一句话的叙述段，会让文章变成毫无节奏的“哒、哒、哒”电报体或伪古风散文诗。
- **正常叙述段（2–5 句，60–150 字）**：同一个视角焦点下的连贯动作、眼前细节和即时反应，必须**拢在同一个自然段里写扎实**。段落内部要有长短句交错和起承转合。
- **什么时候才分段**：
  1. **换人说话**（一段只属于一个说话人，不同角色的台词绝不混在同一段）。
  2. **焦点/镜头转移**（从写手里的器物切到远处的动静，或从甲切到乙）。
  3. **时间或空间推进**。
  4. **极少数需要重锤落点的短段**（全章单句独立成段的叙述句控制在 **3–5 处以内**，用多了立刻失效变成端腔）。
- **对白与动作的配合**：
  - 说话人顺手的小动作、神态可以和他的台词写在同一段（放在台词前、中、后均可），不必把每个“他抬起头”都拆成独立一行。
  - 若动作描写较长（超过两句），或属于**听话人的反应**，则另起一段。

### 3. 排版正误直观对比

❌ **错误示范（一句一行碎段 + 无缩进无空行 + 旁白总结腔）**：
> 九曲黄河阵转到第七日，阵里的黄沙已经卷不动了。
> 云霄盘坐在阵眼，混元金斗悬在头顶，斗上浊光黯淡得像一盏将熄的灯。
> 她唇边金血擦了又渗，束发的白玉簪不知何时崩去了半截。
> 琼霄握剑的手背上全是细小的血口。
> 碧霄靠着她另一侧的肩膀，胸口起伏得像个破风箱。
> 三日三夜，姐妹三人没有合过眼。
> 说法没等来，等来了那两位。

✅ **正确示范（自然段落聚拢 + 全角缩进与空行 + 当下鲜活交互）**：
> 　　阵眼里的黄沙彻底歇了，连最后一缕灰土都贴着地面落定。云霄曲起两指，想把悬在头顶的混元金斗往回引一寸，指尖刚凝起一点清光，喉头便涌上一股铁锈味。她偏头咽了下去，金斗在半空晃了晃，终归没能落回掌心。
>
> 　　“大姐，别催动灵机了。”琼霄从斜刺里伸过手，一把按住她的腕子。那只握了七日剑的手掌心全是干裂的血口，蹭在云霄袖口上，刮得云锦沙沙作响，“外头那些阐教弟子半个时辰前就撤了叫骂，营门大开，不对劲。”
>
> 　　靠在两人身后的碧霄听见动静，撑着剑鞘要往起站，膝盖一软又跌坐回去，只抓着云霄的衣摆低声道：“他们不来破阵，难不成真去请玉虚宫那位了？”

## 三、场景与细节写法

- **描写跟着视角人物当下的动作走**：不要写静态的“战损手办展示”（如挨个汇报唇边渗血、长发散乱、白玉簪断半截、手背血口）。细节必须在动作里带出来——比如伸手去扶人时伤口裂开、低头喝水时看见水里漂着沙子。
- **禁止“不知何时”式偷懒细节**：“白玉簪不知何时断了”“手背上不知何时多了道伤”是典型的 AI 假细节。东西怎么坏的、伤怎么来的，要么写清当下触感，要么不写。
- **具体事实胜过比喻**：一个场景挑一两个可核对的细节（具体的器物、数字、声音、方位、触感）写透，不要用一串比喻糊弄。
- **视角守住**：第三人称限知时，只写视角人物能看到、听到、推断出的东西。不要突然切到城头另一个人的脑子里报一段心理活动，也不要替角色知道他不可能知道的事（对照 `memory/state.md` 的“已知秘密”）。
- **设定靠使用带出来**：法宝有什么威能、阵法有什么代价，在角色催动它、承受反噬的动作里体现，不写设定词条说明书。

## 四、对白写法

- **拒绝“宣言/口号式”台词**：活人吵架、交锋不会上来就念人物小传或喊口号（如“逆天而行，当伏诛！”“要杀便杀，XX没有跪着的种！”）。人说话会有具体的话头、会抓对方的破绽、会冷嘲、会避重就轻、会说半截话。
- **拒绝“脸谱神态前缀 + 冒号”排队**：不要连续三段都是 `甲淡得没有温度：“……”` → `乙红着眼骂道：“……”` → `丙横剑冷笑：“……”`。去掉“冷笑”“红着眼”“淡得没有温度”，改写他们手上的小动作，或者干脆不加标签直接接话。
- **千人千声**：不同身份、性格的角色，句式长短、用词习惯、称呼方式必须能区分（对照 lore 中的“说话方式”）。大人物的威严靠“少说废话、直接定处置”，不靠端着架子念文言判词。

## 五、去 AI 味核心禁令（写前必看）

完整黑名单与改写方法见 `references/anti-ai.md`。以下 **8 条高危 AI 病** 必须在写作时主动规避：

1. **禁“金句病/端腔收尾”**：严禁在段末或转折处写回环顶真、对偶判词、格言警句（如“说法没等来，等来了那两位”“有救没有救，圣人一句话”“圣人不与将死之人辩”“来了又去、去了又来”）。
2. **禁“否定式装逼句”**：严禁“天穹裂开的时候没有雷，也没有火”“他没有哭，也没有闹，只是……”“不是A，而是B”“不仅……更是……”。直接写发生了什么。
3. **禁“破折号补刀癖”**：严禁用 `——` 在句尾追加旁白解释、心理说教或煽情批注（如“她们只当听不见——大兄的仇，几句骂是还不清的”）。全章破折号不超过 2 处。
4. **禁“死比喻与换壳比喻”**：不是把“仿佛”换成“像/如/般”就不算 AI 味！严禁“像一盏将熄的灯”“像个破风箱”“像被一只无形的手按下”“潮水般涌来”“瘫坐如泥”“像是天也在等一个结果”等陈腐比喻。全章比喻不超过 3 处，拿不准就用白描。
5. **禁“旁白宿命腔与偷懒词”**：严禁“不知何时”“终究只能”“自始至终”“这一刻”“他知道，”“某种”“空气凝固”“落针可闻”。
6. **禁“五官肌肉套话”**：严禁“眼中闪过一丝……”“嘴角勾起一抹……”“淡得没有温度”“青筋暴起”“指节泛白”“瞳孔骤缩”“红着眼”“深吸一口气”。
7. **禁“情绪直述与段尾升华”**：不写“她感到悲愤/委屈”，不写段末总结感悟，停在具体的动作、物象或台词上。
8. **禁“句式结构复制”**：连续三句主谓结构相同、字数相近，或连续三段以同一种词（人名/代词）开头，必须打散重组。

## 六、写完自检

1. 跑 `python3 .agents/skills/novel-core/scripts/novel.py lint <文件> --min <下限> --max <上限>`。硬错误全部修掉；若有“碎段/一句一行倾向”“破折号过多”或 AI 味命中，按 `references/anti-ai.md` 逐处改写。
2. **排版目检**：确认段首缩进与段间空行规范统一；检查是否存在连续单句成段的“电报/散文诗”排版，有则合并为饱满的自然段。
3. **场景目检**：通读前 500 字和中间转场处，看是不是在写“当下实时发生的动作与对话”，有没有混入大段“这事本是……那日……后来……”的旁白总结或回忆梗概。
4. **金句清洗**：扫一遍每段最后一句话，凡是在“摆造型、下判词、玩顶真对偶、替读者总结”的句子，全部删掉或改成平实的动作。
5. **章纲核对**：每个节拍是否都落成了具体场景（没被压成梗概）、伏笔与禁区是否遵守、有无纲外擅自新增的专名/设定（有则列出请用户定夺）。
