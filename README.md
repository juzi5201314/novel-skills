# 网文创作技能套件

**让 AI 成为你的网文助手，专注剧情对话，幕后工作全自动。**

## 快速开始（5 分钟）

### 1. 创建新书

```
你：开一本洪荒流小说，主角穿越成鸿钧道童
```

Agent 会问你几轮选择题（类型、卖点、文风等），然后自动生成：
- 标准目录结构
- AGENTS.md（作品档案，每次会话自动注入）
- 主角、世界观、第一卷大纲

### 2. 写第一章

```
你：写第 1 章，主角刚穿越，发现自己在紫霄宫打扫
```

Agent 自动：
- 读取设定和大纲
- 生成章节骨架（让你确认）
- 写完整章（2000-3000 字）
- 检查格式和 AI 味
- 保存到 `chapters/vol01/0001-初入紫霄.txt`
- 同步 memory（角色状态、时间线、摘要）

### 3. 继续写作

```
你：继续写第 2 章
你：审稿一下第 1 章
你：给鸿钧做个详细人设
你：把第 1 章的开头改得更有冲突感
```

全程自然语言，所有文件操作、格式检查、设定同步都在后台自动完成。

| 技能 | 用途 | 触发词示例 |

| **novel-init** | 交互式建书 | "开新书""我想写个 xx 小说" |

| **novel-lore** | 管理设定 | "加个角色""设计个宗门""完善世界观" |

| **novel-explore** | 长文检索梳理 | "搜索 xx""整理时间线""导入旧稿" |
| **novel-craft** | 写作指导（自动应用） | 所有写作场景自动加载 |
| **novel-core** | 约定和工具（基础） | 其它技能自动调用 |
| **novel-webui** | 本地写作台界面 | "打开编辑器""启动 webui""看看章节" |

## 核心特性

### 🎯 零手工操作

- **不用手动跑脚本**：agent 后台自动调用 `novel.py`
- **不用手动编辑 markdown**：所有文件由 agent 维护
- **不用记目录结构**：说"给 xx 加个人设"，agent 知道该写哪个文件
- **不用手动同步状态**：写完一章自动更新 memory

### 🛡️ 防错机制

- **已知秘密检查**：角色不会用他不知道的信息行动
- **伏笔约束**：暗线不会被提前泄露，审稿自动检查
- **设定冲突检测**：新设定自动核对已有 lore 和正文
- **格式自动校验**：全角标点、段落缩进、Markdown 残留

### ✍️ 去 AI 味

- 22 种套话自动检测（"眼中闪过""仿佛""这一刻"...）
- 结构层诊断（总结式结尾、情绪直述、梗概化）
- 8 种文风预设（爽文/仙侠/洪荒/吐槽/悬疑/生活流/古言/冷硬）
- 改写示例和人味来源清单

### 🖥️ WebUI 写作台

```
你：打开编辑器
```

Agent 启动 novel-webui（本地网页），可以在浏览器里翻章节、改正文、管理设定，自动保存、实时字数统计。它是纯编辑工具——AI 写作用对话，手动修改用 WebUI，两边改的文件互相立即可见。

### 🎮 互动模式

```
你：互动写第 5 章
```

Agent 模拟剧情推进，每 300-800 字停在决策点：

```
长老把茶碗推到林川面前。"尝尝，今年的新茶。"
林川没接。这是对峙的第三轮了...

A) 林川喝了那杯茶。【顺势】
B) 门外跑进来一个弟子，脸白得吓人。【反转】
C) 林川突然问："外头那鼓，是你派人敲的？"【埋伏笔】
```

你选择走向，agent 继续写，像玩剧情游戏一样完成整章。

## 目录结构

```
你的书/
├── AGENTS.md              # 作品档案（自动注入）
├── chapters/              # 正文（纯文本，可直接发布）
│   └── vol01/
│       └── 0001-章名.txt
├── outline/               # 总纲、卷纲、章纲
├── lore/                  # 世界书
│   ├── characters/        # 角色
│   ├── locations/         # 地点
│   ├── factions/          # 势力
│   ├── items/             # 物品/法宝
│   ├── world/             # 力量体系、历史
│   └── glossary.md        # 术语表
├── memory/                # 连续性台账
│   ├── state.md           # 当前状态（谁在哪、境界、已知秘密）
│   ├── threads.md         # 伏笔与暗线
│   ├── timeline.md        # 时间线
│   └── summaries/         # 逐章摘要
└── drafts/                # 草稿、审稿报告
```

## 幕后自动化

你看不见，但 agent 在做：

1. **写章前**：自动读 AGENTS.md、memory/state、threads、最近 3 章摘要、上章末尾、相关 lore
2. **写章中**：自动应用文风预设、检查硬规则、避免违反伏笔约束
3. **写章后**：自动跑 `novel.py lint`、自检 AI 味、检查字数
4. **定稿时**：自动同步 7 个地方的 memory，更新 AGENTS.md 进度
5. **建设定时**：自动检查重名、设定冲突、时间线，自动更新 glossary
6. **审稿时**：自动扫描正文、核对 lore、检查伏笔约束

## 进阶功能

- **导入旧稿**：整本 txt 自动切章、反推设定
- **时间线重建**：从已有章节提取事件排序
- **伏笔追踪**：检查全书每条伏笔的埋设和推进
- **人物弧线**：按角色整理态度变化和关键决定
- **批量操作**：一次写多章、整卷审稿
- **全书导出**：合并成单个 txt，自动插入卷标题

## 技术细节

- **纯 Python 标准库**：`novel.py` 工具无依赖，可移植
- **AI 味检测**：22 种套话模式，密度统计，行号标注
- **别名检索**：`novel.py find --entity 鸿钧` 自动带上"道祖""老祖"
- **编码兼容**：支持 UTF-8 和 GB18030
- **Git 友好**：纯文本文件，`.gitignore` 可排除 drafts/

## 常见问题

**Q: 需要手动运行 `novel.py` 吗？**  
A: 不需要。agent 会在后台自动调用。你只需要说"写第 N 章""审稿"，剩下的全自动。

**Q: 章节定稿后忘记确认怎么办？**  
A: agent 会在下次写作时检测到未同步的章节，自动补同步。

**Q: AGENTS.md 会不会越来越长？**  
A: agent 会定期归档已完成卷的规则到 `lore/archive/`，保持 AGENTS.md 在 150 行内。

**Q: 可以管理多本书吗？**  
A: 一书一仓库。多本书放不同目录，各自独立。

**Q: 能用自己的绘图工具吗？**  
A: 可以。agent 生成提示词，你用任意工具画图，放到 `lore/images/` 即可。
